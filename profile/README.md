### subtend

**subtend** *(verb)*: to stretch beneath; to underlie so as to include.

A hypotenuse subtends a right angle. It is the line that runs under the shape and holds it together.

That is the intent here: tools that sit beneath the work rather than in front of it. Construction already has enough software demanding attention. This is meant to be the layer you build on and stop thinking about.

### What we work on

Intelligent tooling for the built environment: the design, planning and delivery of physical things. Recurring themes:

- Extracting structure from the documents construction actually runs on
- Making models and site data usable without a heavyweight platform
- Small, composable tools over monolithic suites

### What we make

- **[ifcdesk](https://subtend.io)**: tools for IFC, the open model format of buildingSMART. Each has one job, runs in your browser and reads your model on your own machine. ifcdesk health and ifcdesk specify are in beta, with more in development.
- **More to come.** ifcdesk is the first product line, not the only one. New ones are announced in [releases](https://github.com/Subtend-io/feedback/releases).

### How it's built

- **Rust** for the core: correctness, predictability, and no runtime surprises
- **WebAssembly** so the same logic runs on the desktop, in the browser and on site
- **Local-first**: your project data should not need someone else's server to be useful
- Libraries before applications; a good crate outlasts a good UI

The code is private for now. The repository open to everyone is [feedback](https://github.com/Subtend-io/feedback).

### Get in touch

There's no contact form and no inbox. Everything goes through one public repository, [Subtend-io/feedback](https://github.com/Subtend-io/feedback):

- **Something doesn't work, or an idea or a question:** [open an issue](https://github.com/Subtend-io/feedback/issues/new/choose)
- **News:** [releases](https://github.com/Subtend-io/feedback/releases), or their [Atom feed](https://github.com/Subtend-io/feedback/releases.atom), which needs no account
- **A security problem:** [report it privately](https://github.com/Subtend-io/feedback/security/advisories/new), never in a public issue

Everything posted there is public, so please don't attach anything that isn't yours to share.
