# subtend

**AI tooling for construction, built in Rust.**

---

### subtend

*verb* — to stretch beneath; to underlie so as to include.

A hypotenuse subtends a right angle. It is the line that runs under the shape and holds it together.

That is the intent here: tools that sit beneath the work rather than in front of it. Construction already has enough software demanding attention. This is meant to be the layer you build on and stop thinking about.

---

### What we work on

AI-assisted tooling for the built environment — the design, planning and delivery of physical things. Some of it is public, some of it isn't yet.

Recurring themes across the repos:

- Extracting structure from the documents construction actually runs on
- Making models and site data usable without a heavyweight platform
- Small, composable tools over monolithic suites

### How it's built

- **Rust** for the core — correctness, predictability, and no runtime surprises
- **WebAssembly** so the same logic runs on the desktop, in the browser and on site
- Preference for **local-first**: your project data should not require someone else's server to be useful
- Libraries before applications; a good crate outlasts a good UI
